# Monad Deployment Guide

This guide explains how to deploy MonadBlitz contracts to the Monad network.

## Network Information

**Monad Mainnet** (Live since Nov 24, 2025)
- **Chain ID**: 143
- **Native Token**: MON
- **Block Time**: 400ms
- **Finality**: 800ms (2 blocks)
- **Throughput**: 10,000 TPS
- **Block Gas Limit**: 200M gas

**Public RPC Endpoints**:
- Primary: https://rpc.monad.xyz (QuickNode, 25 rps)
- Secondary: https://rpc1.monad.xyz (Alchemy, 15 rps)
- High-throughput: https://rpc2.monad.xyz (Goldsky Edge, 300/10s)
- Alternative: https://rpc3.monad.xyz (Ankr, 300/10s)

**Block Explorers**:
- MonadVision: https://monadvision.com
- Monadscan: https://monadscan.com
- Network Visualization: https://gmonads.com

## Prerequisites

1. **Foundry installed** - Use Monad Foundry fork (recommended)
2. **Monad RPC URL** - See public endpoints above
3. **MON tokens** for gas fees
4. **Private key** with sufficient MON balance
5. **Environment variables** configured

## Environment Setup

Create a `.env` file in the project root:

```bash
# Monad Mainnet RPC endpoint (Chain ID: 143)
# Choose one of the public endpoints:
MONAD_RPC_URL=https://rpc.monad.xyz
# Alternatives:
# MONAD_RPC_URL=https://rpc1.monad.xyz
# MONAD_RPC_URL=https://rpc2.monad.xyz
# MONAD_RPC_URL=https://rpc3.monad.xyz

# Deployer private key (NEVER commit this!)
PRIVATE_KEY=0x...

# Fee recipient address (defaults to deployer if not set)
FEE_RECIPIENT=0x...

# Block explorer API key (for verification on MonadVision/Monadscan)
MONAD_EXPLORER_API_KEY=...
```

**IMPORTANT**: Add `.env` to `.gitignore` to prevent committing secrets!

## Deployment Steps

### 1. Load Environment Variables

```bash
source .env
```

### 2. Verify Configuration

monad-mainnet = "https://rpc.monad.xyz"
monad-alt = "https://rpc1.monad.xyz"
```

**Note**: Monad requires using the Monad Foundry fork for accurate gas pricing. Standard Foundry works but gas estimates may differ slightly.ck that your foundry.toml has the Monad RPC configured:

```toml
[rpc_endpoints]
monad = "${MONAD_RPC_URL}"
```

### 3. Check Balance

Ensure your deployer address has sufficient MON for gas:

```bash
cast balance $DEPLOYER_ADDRESS --rpc-url $MONAD_RPC_URL
```

### 4. Simulate Deployment (Dry Run)

Test the deployment without broadcasting transactions:

```bash
forge script script/Deploy.s.sol:DeployMonadBlitz \
    --rpc-url monad \
    --private-key $PRIVATE_KEY
```

### 5. Deploy to Monad

Execute the actual deployment:

```bash
forge script script/Deploy.s.sol:DeployMonadBlitz \
    --rpc-url monad \
    --private-key $PRIVATE_KEY \
    --broadcast \
    --verify \
    -vvvv
```

Flags:
- `--broadcast`: Actually send transactions
- `--verify`: Verify contracts on block explorer
- `-vvvv`: Verbose logging

### 6. Save Deployment Artifacts

After deployment, contract addresses are automatically saved to:
```
deployments/monad-latest.json
```

## Post-Deployment Verification

### Verify Individual Contracts

If automatic verification fails, verify manually:

```bash
forge verify-contract \
    --chain-id <MONAD_CHAIN_ID> \
    --compiler-version v0.8.24 \
    --optimizer-runs 200 \
    <CONTRACT_ADDRESS> \
    src/IdentityNFT.sol:IdentityNFT \
    --etherscan-api-key $MONAD_EXPLORER_API_KEY
```

Repeat for each contract.

### Test Deployment

Run verification script to test deployed contracts:

```bash
forge script script/VerifyDeployment.s.sol \
    --rpc-url monad
```

## Monadarchitecture provides unique performance characteristics:

1. **Parallel Execution**: Independent submissions execute concurrently
   - Multiple users can submit data simultaneously
   - No waiting for sequential processing
   - Scales with validator hardware

2. **Gas Pricing Differences**: Be aware of Monad's repricings
   ```
   Cold account access: 10,100 gas (vs 2,600 on Ethereum)
   Cold storage access: 8,100 gas (vs 2,100 on Ethereum)
   ecRecover precompile: 8,000 gas (vs 3,000 on Ethereum)
   ```
   
3. **High Throughput**: 200M gas per block
   - ~697 max submissions per block
   - 400ms block time = 2.5 blocks/second
   - Theoretical max: 1,742 submissions/sec

4. **JIT Compilation**: Faster execution through native compilation
   - Automatic optimization
   - No code changes needed
   - Benefits complex ZK verification logic:

1. **Parallel execution**: Monad can execute independent transactions in parallel
2. **Lower gas costs**: Take advantage of Monad's efficient execution
3. **Batch operations**: Consider batching for better throughput

### Monitoring

Monitor your contracts on Monad:

```bash
# Watch for events
cast logs \
    --address <CONTRACT_ADDRESS> \
    --rpc-url monad
```

## Upgrading Contracts

If you need to upgrade verifiers or other components:

1. Deploy new verifier contract
2. Call setter functions to update addresses:

```bash
# Update identity verifier
cast send <IDENTITY_REGISTRY_ADDRESS> \
    "setVerifier(address)" <NEW_VERIFIER_ADDRESS> \
    --rpc-url monad \
    --private-key $PRIVATE_KEY
```

### Transaction Costs (From Test Suite)

| Operation | Gas Cost | Approx MON (100 gwei) |
|-----------|----------|----------------------|
| Register Identity | ~161K gas | 0.0000161 MON |
| Create Campaign | ~333K gas | 0.0000333 MON |
| Submit Data | ~287K gas | 0.0000287 MON |
| Release Payment | ~104K gas | 0.0000104 MON |

**At 100 MON-gwei base fee:**
- Deployment: ~0.0043 MON ($2-5 USD equivalent)
- Per submission: ~0.0000287 MON ($0.01-0.05 USD equivalent)

**Economics:**
- Users can profitably submit data worth $0.10+
- Platform 2.5% fee remains viable
- 10-100x cheaper than Ethereum mainnetnts are correct
- Use `--via-ir true` flag if needed
